# MakeHuman base mesh (CC0)

Unmodified files from [makehumancommunity/makehuman](https://github.com/makehumancommunity/makehuman):
`makehuman/data/3dobjs/base.obj` (basemesh hm08), `makehuman/data/rigs/default.mhskel` and
`default_weights.mhw`. All three were released as **CC0** by their copyright holders (Data Collection AB,
Joel Palmius, Jonas Hauquier); see the headers inside each file.

The body-scan simulation (`src/sim/`) poses this mesh with linear blend skinning, renders it as camera
"photos", and slices the posed mesh to get ground-truth girths and lengths.
